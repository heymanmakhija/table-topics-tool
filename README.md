# Table Topics Spinner

A fun and interactive web app for Toastmasters meetings / Spin the wheel / Pick a topic / Own the stage.

## Description

This project is a digital wheel spinner designed for Table Topics sessions in Toastmasters clubs. It features 10 engaging debate topics, each with a scenario and prompt to inspire impromptu speeches. The wheel spins with a random feel but follows the list order sequentially, keeping the UI exciting while maintaining structure.

## Features

- Interactive spinning wheel with 10 topics
- Lo-fi hip-hop background music (toggleable)
- Confetti animation on topic reveal
- Option to remove topics after spin or keep them
- Responsive design for desktop and mobile
- Sequential topic selection / no true randomness

## How to Use

1. Open the app in your browser
2. Click the "SPIN!" button to start the wheel
3. Watch the wheel spin for 5 seconds
4. The selected topic appears with icon, title, scenario, and prompt
5. Toggle "Remove after spin" to eliminate used topics
6. Use "Reset All" to start fresh
